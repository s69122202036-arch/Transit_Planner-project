รายงานสรุปโครงงาน — ไปไหนดี (Thai Transit Graph Planner)

1. ชื่อโครงงาน
การพัฒนา Interactive Web Application ด้วยแนวคิด Graph Theory และ Tree
หัวข้อ: ระบบวางแผนการเดินทาง MRT กรุงเทพฯ “ไปไหนดี”

2. แนวคิดระบบ
ระบบจำลองการวางแผนเดินทางโดยใช้สถานี MRT ในกรุงเทพมหานครเป็นข้อมูลจริงเชิงโครงสร้าง
ผู้ใช้เลือกต้นทางและปลายทาง ระบบสร้าง Graph จากสถานีและ Edge แล้วใช้ Dijkstra หาเส้นทางที่มี Total Weight ต่ำสุด
โดย Weight หลักใน Graph คือเวลาเดินทางโดยประมาณของแต่ละ Edge

3. Graph Theory
Vertex = สถานี MRT
Edge = การเชื่อมต่อระหว่างสถานีที่อยู่ติดกันในชุดข้อมูล
Weighted Edge = เวลาเดินทางโดยประมาณ (นาที)
Adjacency List = object `graph` ใน app.js
Path = ลำดับสถานีจากต้นทางถึงปลายทาง

ตัวอย่าง Path:
สวนจตุจักร → ลาดพร้าว → สุทธิสาร → สุขุมวิท → สามย่าน

4. Tree
Root = ทุกระบบขนส่ง
Parent = รถไฟฟ้า MRT
Parent = สายสีน้ำเงิน / สายสีม่วง
Leaf = สถานีจริง
Path ของ Tree จึงเป็น เช่น
ทุกระบบขนส่ง → รถไฟฟ้า MRT → สายสีน้ำเงิน → สวนจตุจักร

5. Dijkstra
เริ่มต้นระยะทางของต้นทางเป็น 0 และจุดอื่นเป็น Infinity
เลือก Vertex ที่มีระยะทางต่ำสุดและยังไม่ถูกประมวลผล
ตรวจ Neighbor ทุกตัวและทำ Relaxation
ทำซ้ำจนถึงปลายทาง
ผลลัพธ์คือ Shortest Path ตาม Weight ที่กำหนด

6. ค่าโดยสาร
ใช้ค่าโดยสารอ้างอิงจาก BEM ที่ตรวจสอบจากหน้าผลคำนวณค่าโดยสาร
ข้อมูลที่ตรวจสอบ เช่น สวนจตุจักร–สามย่าน 44 บาท, ท่าพระ–สวนจตุจักร 44 บาท,
ท่าพระ–เตาปูน 37 บาท, ท่าพระ–ลาดพร้าว 44 บาท, ท่าพระ–สุทธิสาร 44 บาท
ระบบจะติดป้าย “ประมาณ” หากคู่สถานีที่ผู้ใช้เลือกไม่มีข้อมูลที่ตรวจสอบไว้ในชุดข้อมูล

7. ประโยชน์
Graph ช่วยแทนความสัมพันธ์และการเชื่อมต่อของสถานี
Dijkstra ช่วยค้นหาเส้นทางที่มีต้นทุนตาม Weight ต่ำสุด
Tree ช่วยจัดข้อมูลสถานีแบบลำดับชั้น ทำให้ผู้ใช้เข้าใจการเลือกจากระบบขนส่ง → สาย → สถานี

8. Prompt AI ที่ใช้
- ออกแบบเว็บ 4 หน้าให้สอดคล้องกับเกณฑ์ Graph Theory และ Tree
- เขียน JavaScript Weighted Graph + Adjacency List + Dijkstra
- ออกแบบ Tree Picker 3–4 ระดับและอธิบาย Root/Parent/Child/Leaf/Path

9. หมายเหตุการนำเสนอ
ควรสาธิตจากหน้า 1 เลือก “สวนจตุจักร → สามย่าน”
จากนั้นกดค้นหา → อธิบาย Graph และ Path → เปิดรายละเอียด → เปิด e-Ticket
และชี้ให้เห็นว่า 44 บาทเป็นค่าโดยสารอ้างอิงที่ตรวจสอบจาก BEM
